# Filtro de brilho

O filtro roda no MVP antes das métricas de textura. A decisão usa `Δμ` e saturação no tom 31; LL da Wavelet é salva como leitura complementar do brilho. O eixo de densidade da Wavelet (`density_status`) também é salvo no MVP, ao lado do filtro; como os dois convivem ainda será decidido.
